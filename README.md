# Anomaly-Detection-in-Enron-s-Network

Project focused on large-scale anomaly detection combining Natural Language Processing and graph-based modeling techniques. The Enron email corpus (500k+ emails) was processed through extensive text preprocessing, cleaning, feature engineering, and dimensionality reduction to handle noisy and unstructured data. Semantic representations were extracted using Transformer-based models (BERT) to detect content-level anomalies, while Graph Autoencoders were applied to the email communication network to identify structural irregularities and changes in interaction patterns. The project integrated textual and network-level analysis to uncover both semantic and topological anomalies in a complex real-world dataset.
